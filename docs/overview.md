# Обзор проекта

## Что это такое

Tennis App — это инструмент для разметки видео настольного тенниса и обучения нейросети, которая умеет находить мяч на каждом кадре.

Проект состоит из трёх независимых частей:

```
┌──────────────────────────────────────────────────────┐
│  1. Веб-аннотатор                                    │
│     Браузерный интерфейс для разметки видео          │
│     → сохраняет позиции мяча в JSON                  │
├──────────────────────────────────────────────────────┤
│  2. TrackNet                                         │
│     Нейросеть, обученная на этой разметке            │
│     → предсказывает позицию мяча на новых видео      │
├──────────────────────────────────────────────────────┤
│  3. Вспомогательные скрипты                          │
│     Визуализация, YOLO-детекция, отладка             │
└──────────────────────────────────────────────────────┘
```

## Почему такой подход

### Проблема с YOLO

YOLO — это стандартная модель для детекции объектов. Но для маленького быстрого мяча она плохо работает по нескольким причинам:

- **Видит только один кадр** — не знает, что было секунду назад, не понимает движение
- **Мяч маленький** — занимает 10–30 пикселей, YOLO теряет его
- **Смаз** — при быстром движении мяч размывается, YOLO его не распознаёт

### Решение — TrackNet

TrackNet решает эти проблемы:

- **Видит 3 кадра сразу** — понимает направление и скорость движения
- **Выходной формат — тепловая карта** — вместо жёсткого bbox предсказывает вероятность положения мяча в каждой точке кадра. Это устойчиво к смазу.
- **Маленькая архитектура** — обучается на 500–1000 примерах

## Как всё связано

```
Шаг 1: Разметка
  dataset/videos/*.mov  →  [Веб-аннотатор]  →  dataset/ball_annotations.json

Шаг 2: Обучение
  dataset/ball_annotations.json + видео  →  [train_tracknet.py]  →  weights/tracknet_best.pt

Шаг 3: Использование
  Новое видео  →  [infer_on_video.py]  →  side-by-side MP4 (трекинг + тепловая карта)
```

## Файловая структура

```
tennis-app/
│
├── main.py                    # Запуск веб-сервера
├── train_tracknet.py          # Запуск обучения TrackNet
├── infer_on_video.py          # Применить TrackNet к видео (side-by-side)
│
├── dataset/                   # Данные
│   ├── videos/                # Исходные видео (.mov)
│   │   ├── normal_point/
│   │   ├── serve_into_net/
│   │   ├── sasha_tichka/
│   │   └── soplya_setka/
│   ├── ball_annotations.json  # Позиции мяча (cx, cy per frame)
│   └── annotations.json       # Игровые события (net/bounce/hit)
│
├── weights/                   # Веса моделей
│   ├── tracknet_best.pt       # Обученный TrackNet
│   └── yolo_det.pt            # YOLO-детектор (мяч, стол, сетка, ракетки)
│
├── tracknet/                  # Код нейросети TrackNet
│   ├── model.py               # Архитектура (UNet со skip connections)
│   ├── dataset.py             # Загрузка данных для обучения
│   ├── heatmap.py             # Генерация тепловых карт
│   └── train.py               # Цикл обучения
│
├── model/                     # Pydantic-схемы данных
│   └── schemas.py
│
├── webapp/                    # FastAPI бэкенд
│   ├── app.py                 # Фабрика приложения
│   ├── routes.py              # API эндпоинты
│   ├── video.py               # Работа с видеофайлами
│   ├── storage.py             # Хранение событийных аннотаций
│   ├── ball_storage.py        # Хранение ball-аннотаций
│   ├── detector.py            # YOLO-детектор (singleton)
│   ├── tracknet_detector.py   # TrackNet-детектор (singleton)
│   └── static/
│       └── index.html         # Весь фронтенд (один файл)
│
└── docs/                      # Документация
```

## Зависимости

| Библиотека | Зачем |
|---|---|
| `fastapi` + `uvicorn` | Веб-сервер и API |
| `torch` + `torchvision` | Нейросети (TrackNet, 3D CNN) |
| `ultralytics` | YOLO-модели |
| `opencv-python` | Чтение видео, работа с кадрами |
| `pydantic` | Валидация и сериализация данных |
| `numpy` | Работа с массивами (тепловые карты, кадры) |
| `tqdm` | Прогресс-бары при обучении |
| `httpx` | HTTP-клиент для VLM API |
